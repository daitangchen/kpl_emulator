# KPL 战队经营模拟器

一个纯前端、零依赖的网页小游戏：你是 KPL 战队的老板兼总经理，任选 18 支真实战队之一，
**抽卡组建首发五人**，从 **B 组**出发，最多经营 **4 个赛季**。带队往上爬的同时，别让俱乐部先破产。

> 📄 完整设计思路（需求演进、赛制考据、系统设计、平衡基线、Bug 档案）见 **[设计文档.md](设计文档.md)**
> 本文件只讲怎么跑和怎么开发。

  - 建队页与休赛期属于多步表单，始终保持可滚动。

## 当前赛制（依据 2026 赛季真实规则）

全年顺序：**春季赛 → 挑战者杯 → 夏季赛 → 年度总决赛**

| 赛事 | 赛制 |
|---|---|
| KPL 春季赛 / 夏季赛 | 常规赛三轮（抽签分组 → S/A/B 重组 → 卡位赛 → 组内单循环）+ 8 强双败季后赛 |
| 挑战者杯 | 跳过 32 进 8，直接 8 强双败；决赛 BO9 |
| 年度总决赛 | 12 队按年度积分入围 → 擂台赛（大师组/精英组）→ 突围赛 → 8 强双败淘汰赛 |

关键规则落地情况：

- 常规赛 **BO5**，季后赛/卡位赛/挑杯/年总 **BO7**，挑杯与年总决赛 **BO9**
- **第一轮结束按组内名次重组**：各组 1-2 名 → S 组、3-4 名 → A 组、5-6 名 → B 组
- **B 组后四名提前结束赛季**（第三轮起不再出战）
- 卡位赛：**按第二轮战绩名次**，S 组第 5/6 名 vs A 组第 2/1 名、A 组第 5/6 名 vs B 组第 2/1 名，BO7 胜者进高组
- **季后赛（8 强双败 · 官方 M1~M10）**：种子 1-4 进胜者组、5-8 进败者组
  - M1 第5vs第8、M2 第6vs第7（败者组首轮）；M3 第1vs第4、M4 第2vs第3（胜者组首轮）
  - M5/M6 败者组第二轮（败者组首轮胜者 vs 胜者组首轮败者）；M7 胜者组决赛
  - M8 败者组第三轮、M9 败者组决赛、F 总决赛；名次：1 / 2 / 3 / 4 / 并列5 / 并列7
- **挑战者杯 & 年度总决赛淘汰赛**：同为 8 强 BO7 双败（挑杯决赛 BO9）
- 年总：擂台赛组外单循环，大师组前 4 + 精英组第 1 直接进淘汰赛；大师组 5/6 与精英组 2-5 打突围赛争 3 个名额
- 第 1 赛季玩家固定从 B 组出发；第 2 赛季起保留上季末组别
- **终结名次**：季后赛 8 队按淘汰赛战斗名次（冠军 = 第 1）；9-18 名按常规赛战绩（`rankMode: 'record'`）或严格按组别（`'division'`）

## 抽卡建队

选定战队后，首发五人由抽卡决定，不再手挑名单：

- 五个位置各抽一次，球员从全联盟卡池随机产生
- 稀有度按**该位置的相对水平**分档：`SSR 传说 8%` / `SR 史诗 30%` / `R 稀有 36%` / `N 普通 26%`
- **保底**：连抽两次没出史诗及以上，下一次保底史诗
- **重抽**：前 3 次免费，之后消耗资金（80 万起，逐次 ×1.6），边抽边感受预算压力
- 抽到的球员会从原战队转会过来，原队开季自动补位；抽中的首发按玩家战队档位重算年薪，重抽花掉的现金从初始预算里扣

## 比赛模拟规则（按需求定制）

```
BO5 ：一次模拟 → 直接出最终比分（3-0 / 3-1 / 3-2）

BO7 ：上半场 → 模拟第 1-3 局
      → 【中场调整】换人 / 临场布置（花现金，本场剩余局战力 +2.5）
      → 下半场 → 模拟第 4-6 局
      → 若 3-3 → 单独模拟第 7 局【巅峰对决】

BO9（挑杯/年总总决赛）：前 4 局 → 中场调整 → 第 5-7 局 → 第 8 局 → 巅峰对决第 9 局
```

- 自家战队的 **BO7/BO9**：分两段推进，上半场打完会停下来给你一个调整窗口（换人 / 花钱做临场布置 / 不调整），再打下半场；3-3 时单独出巅峰对决
- **BO5（常规赛）**：一次打完，胜负必定是 3-0 / 3-1 / 3-2（曾经因为分段 bug 被误打成 BO3）
- 其余比赛（常规赛、其他战队的比赛）：一次算出最终比分，比分不再只有 3-0

## 经营系统

- **三线生死**：资金（现金 < 0 连续 2 季 → 资金断裂）、战绩（连续 2 季排名倒数三 → 解雇）、声望（影响赞助与转会吸引力）
- **资金决策（每轮比赛后）**：赛果页会给出一张「本轮资金决策」卡 —— 既能当场花钱特训最弱球员、提升团队士气/默契，也能**接一档商务赚钱**，或跳到「训练」「财务」页做更细的操作
- **商务运营（赚钱）**：运营短视频 📱 / 直播带货 🎥 / 商业代言 💼 / 综艺录制 🎬，报价随声望水涨船高（声望 50 → 报价翻倍）。代价是疲劳：每 1 点疲劳 **-0.2 战力**，有赛季次数上限与疲劳上限（40）。AI 战队不做商务，这是你独有的财路
- **训练系统**：花现金直接给首发球员的操作 / 意识 / 团战 / 英雄池各 +1；成本随「该项已练次数」「该球员本赛季总投入」「球员水平」递增；每项每季最多 +6、每人每季最多 +16。能力提升会推高身价，但已签合同年薪不变 —— 钱花在这里，就少一笔转会预算
- **财务**：收入 = 联盟分成（按上季名次 0.48×~1.40×）+ 赞助（随声望）+ 赛事奖金 + 门票 + 周边 + 赢球奖金；支出 = 选手薪酬 + 基地运营 + 转会费 + 青训投入 + 训练 / 团队投入（后两者立即扣现金，转会费在赛季结算时扣）
- **薪资分两层缩放**：数据表存的是选手市场价，先乘全局系数 `WAGE_SCALE`（0.45）折算成俱乐部可承受的人力成本，再乘球队档位系数（S 1.0 / A 0.82 / B 0.66）
- **不夺冠就要亏钱**：中游队伍每季固定收支约 -200 ~ -430 万，必须靠赛事奖金（春/夏冠军 360、挑杯冠军 500、年总冠军 2000）翻正
- 硬上限 4 个赛季，到期进入生涯评价（S/A/B/C/D）
- **强制结束优先于赛季上限**：真破产/被解雇时不会以"四个赛季结束"收场

### 休赛期（每季结算后）

1. **球员成长与老化**：全体年龄 +1，年轻球员涨球（受潜力上限约束）、老将先掉操作后掉意识；身价随实力与年龄重估
2. **球员个人剧情线**：每名球员有稳定性格（10 种原型，影响成长速度 / 薪资诉求 / 被挖角倾向），赛季结算后更新成长弧，并在更衣室、赛果、休赛期推送符合性格的采访发言
3. **青训营**：每年自动到队一名新秀（潜力 78-94），可额外投入 60/140/260 万再抽一名，投入越高天赋越好
4. **转会市场**：
   - 其他战队会挂牌球员，按实力/潜力/年龄/位置稀缺度定价，买入要付转会费（赛季结算时扣除）
   - **工资帽**软约束：全队年薪不得超过当季预估固定收入的 1.35 倍
   - 其他战队会主动报价你的球员（战绩越好、球员越年轻越容易被挖），接受立刻回血（85%），拒绝会掉士气
   - 卖出首发会导致位置空缺，开季前会自动补位（替补 → 青训 → 临时自由人）

### 突发事件（15 个模板）

每个赛程节点有概率触发（常规赛阶段 22%、淘汰赛/关键节点 45%），一季约 5-11 次。每个事件 2-3 个选项，**所有选项都有代价**，没有纯赚的：

核心要求加薪 / 赞助商要求商业活动 / 版本大改 / 教练被挖角 / 队内矛盾 / 主力伤病 / 资金告急 / 主场城市邀约 / 青训苗子冒头 / 舆论危机 / 直播平台合约 / 季后赛奖金承诺 / 基地涨租 / 粉丝见面会 / 自由人试训

- 每名选手额外带一套**性格与成长弧**（确定性生成，随存档持久化），用于球员档案、更衣室动态与赛后采访
- 数据基准为 2026 赛季。已核实的冲突取舍写在其来源注释里（`src/data/players.js` 头部），
  例如归期归 RW 侠、今屿归 RW 侠、昭珏归 WB、百炼归 WST 等；西安 WE 与 WST 部分位置为推定

## 当前平衡性基线

`node tools/calibrate.mjs 4`（72 次完整生涯，模拟普通玩家的休赛期操作）：

| 指标 | 数值 |
|---|---|
| S 档平均终局名次 | 4.4 |
| A 档平均终局名次 | 8.7 |
| B 档平均终局名次 | 15.0 |
| B 档被解雇率 | ≈ 10% |
| 管理良好的破产率 | 0%（只有乱花钱才会破产，见 test-failure.mjs） |

> 口径变化：v1.5 把淘汰赛改成官方 M1~M10 双败结构（胜者组前 4 只打 2 场首轮，强队会更早互相淘汰，S 档名次因此从 2.8 变成 4.4 —— 这是真实赛制的结果，不是退化）。
> v1.4 修复了"玩家常规赛被误打成 BO3"与疲劳系数（0.05 → 0.2）。
> v1.2 修复了"终结名次按跨组胜场排"，v1.3 修复了"非玩家比赛全是 3-0"的快速模拟 bug。
> 后者让 AI 对局真正按战力分出胜负，整份基线因此显著变化（v1.2 的 S 档 1.8 / 解雇 26% 是在错误的模拟结果上测出来的）。
> 现在 S/A/B 三档的名次梯度依然清晰。选手剧情线、抽卡、训练都**不参与 AI 决策**，不影响这份基线。

`node tools/test-failure.mjs` 用"强队 + 每季资不抵债"确定性验证破产路径（第 2 赛季资金断裂），
用"弱队完全不作为"验证战绩崩盘路径（约 7/8 触发）；另附"败家玩法"的参考结果。
